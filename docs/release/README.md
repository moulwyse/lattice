# Release records

Historical audit records from the first public export of Lattice. They were
written at the repository root and moved here unchanged, so file paths inside
them (for example in `PUBLIC_FILE_MANIFEST.sha256`) refer to the original
root-level locations.

| File | Contents |
| --- | --- |
| [FINAL_RELEASE_AUDIT.md](FINAL_RELEASE_AUDIT.md) | Final pre-release audit: commands, results, and corrections. |
| [PUBLIC_EXPORT_REPORT.md](PUBLIC_EXPORT_REPORT.md) | How the public export was prepared and sanitized. |
| [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md) | The release checklist. |
| [RELEASE_CHECKLIST_STATUS.md](RELEASE_CHECKLIST_STATUS.md) | Status and evidence for each checklist item. |
| [PUBLIC_FILE_REVIEW.csv](PUBLIC_FILE_REVIEW.csv) | Per-file review of the export. |
| [PUBLIC_FILE_MANIFEST.sha256](PUBLIC_FILE_MANIFEST.sha256) | SHA-256 manifest of the reviewed export. |
| [DEPENDENCY_INVENTORY.csv](DEPENDENCY_INVENTORY.csv) | Dependency and license inventory from the lockfile. |

Current dependency information is in [DEPENDENCIES.md](../../DEPENDENCIES.md).
